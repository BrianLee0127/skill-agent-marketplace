# Skill & Agent Marketplace

Private Claude Code plugin marketplace.

## How to use (team members)

1. Make sure you have access to this repo.
2. In Claude Code, run:

   /plugin marketplace add BrianLee0127/skill-agent-marketplace

3. Then run /plugin and install "design-skills".

## Plugins

- design-skills: 13 design skills for premium frontend work, brand kits, image generation direction, and redesigns.
