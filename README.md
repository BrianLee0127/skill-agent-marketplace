# Tanah Co Plugin Marketplace

Private plugin marketplace for the Tanah Co team.

## How to use (team members)

1. Make sure you have access to this repo (ask Brian to invite you).
2. In Claude Code, run:

   /plugin marketplace add BrianLee0127/tanah-marketplace

3. Then run /plugin and install "tanah-design".

## Plugins

- tanah-design: 13 design skills for premium frontend work, brand kits, image generation direction, and redesigns.
